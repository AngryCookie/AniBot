# ROADMAP 2026: AniBot

## Фаза 1: Foundation (Реализовано)
**Цель:** Базовая инфраструктура и core-механики

- Discord-бот с async архитектурой
- Web Admin Panel (FastAPI + SQLAlchemy)
- Docker + Docker Compose
- Feature flags (глобальные и серверные)
- SQLite с async поддержкой
- Economy: валюта, транзакции, балансы
- Leveling: опыт, уровни, прогрессия
- Shop: покупка предметов
- Moderation: базовые инструменты
- Betting v1: вымышленные команды, матчи, коэффициенты, Discord UX

---

## Фаза 2: Betting System v2 (Q1 2026)
**Цель:** Полноценная система ставок с гибким управлением

**Backend + Web:**
- CRUD для команд (создание, редактирование, удаление)
- CRUD для матчей (планирование, окна ставок)
- Управление коэффициентами (ручное + автоматическое)
- Статусы матчей: scheduled → open → closed → finished → cancelled
- История всех матчей и ставок

**Discord UX:**
- /bet list — активные матчи
- /bet history — история ставок пользователя
- /bet stats — личная статистика (win rate, ROI)
- Уведомления о начале/окончании матчей (опционально через флаги)
- Auto-complete для выбора матчей в командах

**Логика:**
- Расчет выигрышей с учетом комиссии системы
- Отмена матчей с возвратом ставок
- Tie/Draw как возможный исход

## Фаза 3: Economy & Betting Analytics (Q1-Q2 2026)
**Цель:** Прозрачность экономики и поведенческая аналитика

**Web Admin Panel:**
- Dashboard: оборот валюты, активность ставок, рост пользователей
- Графики: валюта в обращении, инфляция, популярность матчей
- Отчеты по пользователям: топ богатых, топ активных игроков, подозрительная активность
- Аналитика ставок: популярность команд, прибыльность букмекера

**Discord UX:**
- /stats server — публичная статистика сервера
- /stats economy — моя позиция в экономике (топ %)
- Личный кабинет: баланс, история, достижения

**Системные метрики:**
- Tracking всех транзакций (источник, причина)
- Audit log для админских действий

## Фаза 4: Community Mechanics (Q2 2026)
**Цель:** Коллективные цели и ротация ролей

**Monthly Goals:**
- Админы задают цель на месяц (сумма ставок, количество матчей, активность)
- Прогресс-бар в Discord (Rich Embed с обновлением)
- Награда при достижении: бонусная валюта всем участникам или редкий предмет в магазин

**Role Rotation:**
- Автоматическая ротация "Player of the Month" на основе активности
- Роль дает небольшой буст к ставкам или скидку в магазине
- История всех обладателей роли

**Leaderboards:**
- Топ по балансу (месяц/все время)
- Топ по ставкам (количество/сумма)
- Топ по уровням
- Reset таблиц лидеров (сезонность)

## Фаза 5: Progression Systems (Q2-Q3 2026)
**Цель:** Долгосрочная вовлеченность через развитие

**Jobs (Работы):**
- Выбор профессии с кулдауном (раз в X часов)
- Работа приносит валюту + опыт + шанс на редкий дроп
- Профессии с разной волатильностью (стабильная vs рисковая)
- /work, /job change, /job info

**Shop Items с Buffs:**
- Предметы не только косметические, но с эффектами:
  - +5% к выигрышу ставок (24 часа)
  - Скидка 10% в магазине (постоянная)
  - Двойной опыт (1 час)
- Buffs применяются автоматически при покупке или по команде
- Визуальные индикаторы активных баффов в /profile

**Achievements:**
- Система достижений (первая ставка, 100 выигрышей, богач)
- Награды за достижения: валюта, редкие предметы, титулы

## Фаза 6: Monthly / Quarterly Recaps (Q3 2026)
**Цель:** Автоматическая отчетность и вовлечение

**Monthly Recap (автоматический):**
- Личный отчет в DM: баланс на начало/конец месяца, сколько поставил, выиграл/проиграл, уровень вырос
- Server-wide recap в канал: общий оборот, самый крупный выигрыш, топ игроков месяца
- Генерация в первый день месяца

**Quarterly Recap:**
- Расширенная статистика: тренды, сравнение с прошлым кварталом
- Награды за квартал: особые роли или предметы для топ-3

**Admin Recap:**
- Расширенная аналитика для админов в web-панели
- Рекомендации по балансу экономики

## Фаза 7: Yearly Wrapped (Q4 2026)
**Цель:** Годовой итог в стиле Spotify Wrapped

**Автоматическая генерация (декабрь):**
- Персональная инфографика для каждого пользователя:
  - Всего заработано/потрачено
  - Самая прибыльная ставка
  - Любимая команда (по количеству ставок)
  - Уровень в начале и конце года
  - Топ-3 достижения
  - Сравнение с серверным средним

**Server Wrapped:**
- Общая статистика сервера за год
- Самые популярные матчи
- Эволюция экономики
- Топ моменты (крупнейшие выигрыши)

**Формат:**
- Rich Embed с графиками (ASCII или image generation)
- Shareable — пользователи могут постить в канал
- Экспорт в image (опционально, v2)

## Фаза 8: UX Polish (Q3-Q4 2026)
**Цель:** Профессиональный и понятный интерфейс

**Discord UX:**
- Единый стиль всех embeds (цвета, иконки, форматирование)
- Buttons везде где возможно (вместо текстовых команд)
- Modals для ввода данных (сумма ставки, причина перевода)
- Confirmation для необратимых действий
- Error handling с понятными сообщениями (не "Error 500", а "Недостаточно средств")

**Web Admin Panel:**
- Разделение прав: супер-админ vs модератор
- Mobile-friendly интерфейс
- Bulk actions (массовое управление матчами)
- Live preview изменений перед применением

**Onboarding:**
- /start для новых пользователей (краткий туториал)
- Первичный бонус за регистрацию
- Подсказки при первых действиях

## Фаза 9: Infrastructure (Q4 2026)
**Цель:** Масштабирование и доступность

**Hosting:**
- Миграция с SQLite на PostgreSQL (для production)
- Redis для кеширования сессий и rate limiting
- Backup система (автоматические бэкапы БД)

**Public Admin Panel:**
- SaaS-версия: мульти-тенантность (несколько серверов на одном инстансе)
- Регистрация серверов через Discord OAuth
- Subscription tiers (free / premium с расширенными лимитами)

**Rich Presence:**
- Discord Rich Presence для бота ("Managing 5 servers | 120 active bets")
- Status indicators (online/maintenance)

**API:**
- Public API для интеграций (webhooks, export данных)
- Rate limiting и API keys

**Observability:**
- Логирование (structured logs)
- Мониторинг: uptime, ошибки, latency
- Alerts для критических проблем
