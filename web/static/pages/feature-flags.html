Feature Flags

Гибкое включение и отключение экспериментальных функций.

Управление флагами

Добавьте флаги для отдельных модулей, чтобы включать новые возможности без релиза.

  • Флаги применяются мгновенно после сохранения.
  • Поддерживаются индивидуальные настройки для разных серверов.
  • История изменений сохраняется в разделе History.
