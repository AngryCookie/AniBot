Подсказки администратору

  • Как получить Role/Channel ID: включите режим разработчика в Discord, кликните правой кнопкой на роли/канале и выберите «Копировать ID».
  • Developer Mode: Discord → User Settings → Advanced → Developer Mode.
  • Открыть Discord OAuth логин, если сессия завершена или нужен повторный вход.
