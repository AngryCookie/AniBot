## 🎯 Описание проекта

**AniBot** — это инструмент для владельцев и администраторов Discord-серверов, объединяющий Discord-бота и web-панель администрирования для управления внутренней экономикой, аналитикой и системой ставок на вымышленные киберспортивные команды.

### Ключевые особенности

- 🎮 **Контролируемая игровая система** для Discord-серверов
- 📊 **Админ-инструмент**, ориентированный на аналитику
- 🧪 **Песочница** для экспериментов с экономикой и механиками ставок

### Что это за проект

| ✅ Это проект | ❌ Это НЕ проект |
|--------------|-----------------|
| Контролируемая игровая система для Discord-серверов | Не реальный гэмблинг |
| Админ-инструмент, ориентированный на аналитику | Не реальные ставки на киберспорт |
| Песочница для экспериментов с экономикой | Нет интеграции с внешними API матчей |
| | Не фокус на музыке, модерации или развлечениях |

## ✨ Возможности

### 🤖 Discord-бот

- **Слэш-команды** — современный и удобный интерфейс
- **Эфемерные ответы** — приватные сообщения там, где это уместно
- **Экономика** — внутренняя валюта с транзакциями
- **Система ставок** — на вымышленные киберспортивные команды
- **Подтверждение ставок кнопками** (подтвердить / отменить)
- **Флаги функций** — глобальные и на уровне сервера
- **Без реальных денег** и без реальных данных киберспорта

### 🎲 Система ставок (v1)

| Функция | Описание |
|---------|----------|
| Команды | Полностью вымышленные команды |
| Создание матчей | Через web-панель администратора |
| Окна ставок | Настраиваемые временные рамки |
| Коэффициенты | Автоматически генерируемые |
| Типы ставок | Только на победителя (Team A / Team B) |
| Результаты | Определяются системой (случайно с учётом силы команды) |
| Интеграция | Обновление балансов пользователей |

### 🌐 Web-панель администрирования

- ⚙️ **Управление параметрами экономики**
- 🏆 **Управление командами, матчами и событиями ставок**
- 🎛️ **Включение/выключение функций** через флаги
- 📈 **Источник истины** для всей игровой логики

## 🚀 Быстрый старт

### Переменные окружения

Создайте `.env` файл на основе примера:

```env
DISCORD_TOKEN=your_discord_bot_token
DISCORD_CLIENT_ID=your_discord_client_id
DISCORD_CLIENT_SECRET=your_discord_client_secret
DISCORD_REDIRECT_URI=http://localhost:8000/auth/callback
SESSION_SECRET=your_session_secret
SESSION_ENCRYPTION_KEY=your_session_encryption_key
DATABASE_URL=sqlite+aiosqlite:///bot.db
```

### Запуск локально (без Docker)

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Запустите web backend
uvicorn web.main:app --reload --host 0.0.0.0 --port 8000

# 3. Запустите Discord-бота
python -m bot.main
```

### Запуск через Docker Compose

```bash
docker compose up --build
```

## 🤖 Команды Discord-бота

### 💰 Экономика

| Команда | Описание |
|---------|----------|
| `/balance` | Показать баланс |
| `/pay @user <amount>` | Перевод валюты |
| `/daily` | Ежедневный бонус |

### 🎲 Ставки

| Команда | Описание |
|---------|----------|
| `/bet place <match_id> <team> <amount>` | Сделать ставку |
| `/bet list` | Список активных матчей |
| `/bet history` | История ставок |

### 👤 Профиль

| Команда | Описание |
|---------|----------|
| `/profile` | Просмотр профиля |
| `/level` | Уровень и опыт |
