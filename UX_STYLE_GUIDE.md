# Discord UX Style Preset B — Gaming / Tatsu-like

## Embeds
- Заголовок: `🎮 <Screen Title>`.
- Разделы: эмодзи в заголовке раздела (1 эмодзи на раздел, без спама).
- Описание: короткое и понятное (1–2 строки).
- Поля: максимум 6–8 на embed, значения короткие.
- Footer: `⏳ Кнопки активны 60с • AniBot`.
- Цвета:
  - info: blurple/blue
  - success: green
  - warn: orange
  - error: red

## Buttons / Select / Modal
- По возможности использовать кнопки/select вместо ручного ввода аргументов.
- Для дорогих/разрушающих действий использовать `ConfirmView`.
- Timeout для интерактивных view: `60s`.
- По timeout кнопки должны блокироваться (`disabled`).
- Все пользовательские сообщения — на русском, с явным действием.

## Errors
- Единый формат:
  - `❌ <message>`
  - опционально подсказка: `💡 <hint>`
